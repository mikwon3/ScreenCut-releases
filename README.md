# ScreenCut for macOS

화면에서 원하는 영역을 녹화하고 여러 구간을 골라 하나의 MP4로 저장하는 macOS 앱입니다.

## 설치

[최신 설치 파일 다운로드](https://github.com/mikwon3/ScreenCut-releases/releases/latest)

- macOS 15 이상 · Apple Silicon / Intel 지원
- PKG 파일로 설치한 뒤 응용 프로그램에서 ScreenCut을 실행합니다.
- 첫 사용 시 화면 녹화 권한을 허용합니다. 마이크와 가상 키보드를 사용하면 해당 권한도 필요합니다.

## 기능

- 마우스로 영역 선택, 커서 포함 녹화
- 시스템 소리 및 마이크 입력
- 여러 구간 선택·순서 변경·MP4 저장
- 입력 언어에 맞는 한글/영문 가상 키보드, 반투명 표시와 이동
- ScreenCut 메뉴에서 업데이트 확인 및 자동 확인 설정

1.2.0을 처음 설치한 뒤부터 앱에서 업데이트를 받을 수 있습니다. 녹화·저장 중에는 확인과 재시작을 미룹니다. 업데이트 파일은 EdDSA 서명으로 검증합니다.

현재 배포 파일은 Developer ID 서명·Apple 공증을 받지 않은 개발 빌드입니다. macOS 보안 경고가 표시되거나 업데이트 후 녹화·입력 모니터링 권한을 다시 허용해야 할 수 있습니다.

이 저장소에는 설치·업데이트 파일만 게시합니다. 앱 소스는 비공개입니다.
